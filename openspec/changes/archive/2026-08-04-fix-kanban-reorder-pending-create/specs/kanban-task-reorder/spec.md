## MODIFIED Requirements

### Requirement: 並び順の永続化と表現

システムは、列内の並び順を各タスクの `sort_order` として永続化する SHALL。一覧取得時は `status, sort_order, id` の順で並べ、フロントは取得順を列内順序として描画する SHALL。並べ替えの保存はサーバへ反映され、複数カードの `sort_order` が変わる場合も整合した状態で永続化される SHALL。

作成中（サーバーへの登録が未確定）のカードが列に存在する間は、その列に対する並べ替えの**サーバーへの送信のみ**を保留する SHALL。ローカルの見た目（カードの並び順表示）は保留中も即座に反映し、既存のドラッグ操作の体感速度を変えない SHALL。作成が確定（成功または失敗）した時点で、保留していた列の最新の並び順を実IDのみで永続化する SHALL。作成が失敗した場合、当該カードを除いた並び順で永続化する SHALL。作成中のカード自身のIDは、いかなる場合も並べ替えの永続化リクエストに含めない SHALL。

#### Scenario: 並び順がサーバへ保存される

- **WHEN** ユーザーが列内でカードを並べ替える
- **THEN** 影響を受けるカードの `sort_order` が更新され、サーバに保存される
- **AND** 別のクライアント/再読み込みでも同じ並び順で表示される

#### Scenario: 作成中のカードがある列で別カードを並べ替えてもエラーにならない

- **WHEN** ユーザーが列にカードを新規作成した直後（サーバー応答が返る前）に、同じ列の別のカードをドラッグ&ドロップで並べ替える
- **THEN** 並べ替えはエラーにならず、ローカルの表示は即座に新しい順序へ更新される
- **AND** 作成が確定した後、その列の最新の並び順（作成されたカードを含む）がサーバーへ保存される

#### Scenario: 作成が失敗した場合、保留していた並び順は作成中カードを除いて保存される

- **WHEN** 作成中のカードがある列で別カードを並べ替えた後、そのカードの作成がサーバーエラーで失敗する
- **THEN** 失敗したカードは列から取り除かれる（既存の作成ロールバック挙動）
- **AND** 直前に行った並べ替え後の順序は、失敗したカードを除いた形でサーバーへ保存される

#### Scenario: 作成中のカードを含む列間移動でも両列の並べ替えがエラーにならない

- **WHEN** ある列で作成中のカードが存在する間に、別のカードをその列との間でドラッグ&ドロップして列間移動する
- **THEN** 移動元・移動先いずれの列についても並べ替えはエラーにならない
- **AND** 作成が確定した後、両列の最新の並び順がそれぞれサーバーへ保存される
