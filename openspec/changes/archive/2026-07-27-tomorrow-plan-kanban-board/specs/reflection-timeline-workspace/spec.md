## MODIFIED Requirements

### Requirement: 左メインのビュー切替（ビュータブ）

左メインは `タイムライン（完全版） / 一日の配分 / 明日の計画` の3ビューを **ラベル付きの切替コントロール（ビュータブ）** で切り替えられなければならない（MUST）。

- 左メインは、ビュー切替を目的とした**横スクロール（スナップ）を提供してはならない**（MUST NOT）。左メイン内の横スクロールは、ビューの中身（埋め込みカンバン盤面など）を横へめくる操作のためだけに用いられなければならない（MUST）。
- 現在ビューは視覚的に明示されなければならない（MUST）。
- 各ビューは全幅で余白を持って表示し、狭い枠へ複数ビューを同時に圧縮してはならない（MUST NOT）。
- ビュー切替は対象日を変えてはならない（MUST NOT。対象日は日付ストリップが駆動する）。

#### Scenario: ビュータブで3ビューを切り替える
- **WHEN** ユーザーが切替コントロールで「一日の配分」を選ぶ
- **THEN** 左メインは「一日の配分」ビューへ切り替わり、現在ビューが明示される

#### Scenario: 横スクロールではビューが変わらない
- **WHEN** ユーザーが左メインの「明日の計画」ビューで埋め込み盤面を横スクロールする
- **THEN** 盤面の見切れていた列が現れるだけで、左メインのビューは「明日の計画」のまま切り替わらない

#### Scenario: ビュー切替は対象日を保つ
- **WHEN** 対象日が 7/24 のまま左メインを別ビューへ切り替える
- **THEN** 対象日は 7/24 のままで、切替先ビューも 7/24 のデータを表示する

### Requirement: 左右2分割ワークスペース

振り返りタブは、**左＝メイン領域（大）** と **右＝振り返りサイドバー（常時表示・相対的に細い）** の2分割レイアウトでなければならない（MUST）。

- 左メインでタイムライン等を見ながら、右サイドバーで振り返り本文を書けなければならない（MUST。両者は同時に画面上に見えていなければならず＝MUST、片方をめくると他方が隠れる構造にしてはならない＝MUST NOT）。
- 右サイドバーは左メインでどのビューを表示していても常時表示されていなければならない（MUST）。折り畳んで消せる構造にしてはならない（MUST NOT）。
- 右サイドバーは**タブ切替**を持ち、その**タブ構成は左メインの現在ビューによって決まら**なければならない（MUST。詳細は「左ビューによるサイドバーと日付ストリップの駆動」を参照）。
- レイアウトは詰め込み（過度に狭いカラムへ要素を圧縮する構成）を避け、各領域は自領域内でスクロールしなければならない（MUST。ページ全体を縦に流す構成にしない）。

#### Scenario: タイムラインを見ながら書ける
- **WHEN** 左メインでタイムラインビューを表示している
- **THEN** 右サイドバーの振り返り本文エディタは同時に見えており、タイムラインを見ながら本文を入力できる

#### Scenario: サイドバーは常時見える
- **WHEN** 左メインを「一日の配分」や「明日の計画」へ切り替える
- **THEN** 右の振り返りサイドバーは隠れず、そのまま表示され続ける

### Requirement: 日付ストリップによる対象日ナビゲーション

対象日ナビゲーションは、前後の日を横に並べた **日付ストリップ** として画面上部に提供しなければならない（MUST）。ストリップは、**対象日を持つビュー**（タイムライン／一日の配分）および右サイドバーの対象日を駆動しなければならない（MUST）。

- 各日チップは曜日・日番号を表示し、その日の振り返りの **気分を色ドット** で示さなければならない（MUST。未記入の日はドット無し等で区別する）。未来日（＝明日の計画の対象になり得る日）は現在日・過去日と視覚的に区別しなければならない（MUST）。
- 前後移動の矢印（‹ ›）、チップの直接選択、「今日」への即時復帰を提供しなければならない（MUST）。
- 対象日を変えると、左メインの現在ビュー（対象日を持つもの）と右サイドバーの本文・気分・目標日記が対象日のデータへ同期しなければならない（MUST）。
- 左メインが**対象日を持たないビュー**（「明日の計画」＝埋め込みカンバン盤面）のとき、ストリップは無効化されなければならない（MUST。詳細は「左ビューによるサイドバーと日付ストリップの駆動」を参照）。
- このストリップは、従来 `reflection-journal` の右レールにあった「過去の振り返り一覧（日付選択）」の役割を引き継ぐ（別途、日付ピッカーからの任意日ジャンプを併設してよい）。

#### Scenario: 気分ドット付きで前後日が見える
- **WHEN** ユーザーが振り返りタブを開く（左メインはタイムラインビュー）
- **THEN** 上部に前後数日の日付チップが並び、各日の振り返りの気分が色ドットで示され、未記入日はドット無しで区別される

#### Scenario: チップ選択で対象日ビューが同期する
- **WHEN** 左メインがタイムラインまたは一日の配分のときに、ユーザーが別の日付チップを選ぶ
- **THEN** 左メインの現在ビューと右サイドバーの本文・気分・目標日記が、その日のデータへ更新される

#### Scenario: 「今日」で復帰する
- **WHEN** 過去日を表示中に「今日」を押す
- **THEN** 対象日が当日に戻り、全ビューが当日のデータへ更新される

### Requirement: ワークスペースの視覚的忠実性

統合ワークスペースの見た目は参照実装 `ref/reflection/`（盤面ビューとサイドバータブを含む更新後の HTML）に忠実でなければならない（MUST）。配色 hex・寸法・要素アナトミーは参照の値を `rf-*` CSS クラスへ転記する。埋め込みカンバン盤面のカード・列は既存の `kb-*` の意匠をそのまま用いる（MUST）。CSP（`style-src 'self'`）のためインライン `style=` 属性を使ってはならず（MUST NOT）、静的スタイルはクラス、動的値のみ CSSOM で適用する（**フォントのみ** `system-ui` フォールバックを許容する）。受け入れ基準の詳細な画面遷移は companion `ユーザーフロー.md` を唯一の正典とする。

#### Scenario: 参照実装との一致
- **WHEN** 統合ワークスペースを表示する
- **THEN** 左メイン（ビュータブ切替）＋右サイドバー（タブ切替）＋日付ストリップの配色・寸法・レイアウトが `ref/reflection/` の参照実装どおりに描画される

#### Scenario: 埋め込み盤面はカンバンの意匠を保つ
- **WHEN** 「明日の計画」ビューの埋め込み盤面を表示する
- **THEN** 列とカードは既存カンバン（`kb-*`）の配色・寸法で描画され、振り返り専用の別意匠へ描き直されていない

#### Scenario: CSP 適合
- **WHEN** ワークスペースの DOM を検査する
- **THEN** インライン `style=` 属性は存在せず、スタイルは `rf-*` / `kb-*` クラスと CSSOM のみで適用されている

## ADDED Requirements

### Requirement: 左ビューによるサイドバーと日付ストリップの駆動

左メインの現在ビューは、**右サイドバーのタブ構成**と**上部日付ストリップの有効性**の両方を決定しなければならない（MUST）。この対応は次のとおりでなければならない（MUST）。

| 左メインの現在ビュー | 日付ストリップ | 右サイドバーのタブ |
|---|---|---|
| タイムライン（完全版） | 有効（対象日を駆動） | 振り返り本文 / 気分 / 目標の日記 |
| 一日の配分 | 有効（対象日を駆動） | 振り返り本文 / 気分 / 目標の日記 |
| 明日の計画（埋め込み盤面） | 無効（非表示） | 振り返り本文 / 詳細 / アクティビティログ |

- `詳細` タブと `アクティビティログ` タブは、左メインが「明日の計画」ビューのときにのみ存在しなければならない（MUST）。左メインが他のビューへ切り替わったとき、これらのタブは閉じられなければならない（MUST）。
- 左メインが「明日の計画」ビューのとき、日付ストリップは表示されてはならない（MUST NOT）。カンバン盤面は「表示対象日」を持たないため、対象日の選択が盤面へ及ぶかのように見せてはならない（MUST NOT）。
- 「明日の計画」ビューから対象日を持つビューへ戻ったとき、日付ストリップは離脱前の対象日を保ったまま再表示されなければならない（MUST）。

#### Scenario: カンバンビューでストリップが引っ込む
- **WHEN** ユーザーが左メインを「明日の計画」ビューへ切り替える
- **THEN** 上部の日付ストリップは非表示になり、右サイドバーに `詳細` と `アクティビティログ` のタブが現れる

#### Scenario: 他ビューへ戻すと詳細とログが閉じる
- **WHEN** 左メインを「明日の計画」から「タイムライン」へ切り替える
- **THEN** 右サイドバーの `詳細` と `アクティビティログ` のタブは消え、日付ストリップが再表示される

#### Scenario: 対象日は離脱前のまま保たれる
- **WHEN** 対象日を 7/23 にした状態で「明日の計画」ビューへ移り、その後「一日の配分」ビューへ戻る
- **THEN** 日付ストリップは 7/23 を選択した状態で再表示され、「一日の配分」は 7/23 のデータを表示する
