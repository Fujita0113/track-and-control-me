## ADDED Requirements

### Requirement: Windowsログオン時の自動起動
サーバーは SHALL、リポジトリ同梱のセットアップスクリプトを一度実行した後は Windows への
ユーザーログオン時に自動的に起動しなければならない。これにより `npm run server` を手動
実行しなくてもダッシュボードが使える状態になる。

#### Scenario: セットアップ後、ログオンすると自動起動する
- **WHEN** ユーザーが `register-autostart.ps1` を一度実行した後、Windows にログオンする
- **THEN** サーバープロセスが手動操作なしに起動し、いつものポートでダッシュボードに
  アクセスできる状態になる

### Requirement: 自動起動プロセスは非表示で動作する
自動起動されたサーバープロセスは SHALL、コンソールウィンドウを表示せずバックグラウンドで
動作しなければならない。

#### Scenario: 自動起動時にウィンドウが表示されない
- **WHEN** ログオン時に自動起動がトリガーされる
- **THEN** 目に見えるコンソールウィンドウは表示されず、サーバーはバックグラウンドで
  動作し続ける

### Requirement: セットアップ/解除スクリプトは冪等である
自動起動の登録スクリプトは何度実行しても重複登録してはならない(MUST NOT)。解除スクリプトで
元の状態に戻せる SHALL。

#### Scenario: 登録スクリプトを複数回実行しても重複しない
- **WHEN** `register-autostart.ps1` を既に登録済みの状態で再度実行する
- **THEN** 自動起動タスクは1つだけ存在する状態になり、古い登録が残らない

#### Scenario: 解除スクリプトで自動起動を止められる
- **WHEN** `unregister-autostart.ps1` を実行する
- **THEN** 以降のログオン時にサーバーは自動起動しなくなる
