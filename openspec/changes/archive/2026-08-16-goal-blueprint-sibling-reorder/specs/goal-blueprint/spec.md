## MODIFIED Requirements

### Requirement: タスク一覧はキーボードだけで組める

タスク一覧は、マウスを使わずにツリーを組み立てられる SHALL する。次のキー操作を提供 SHALL する。

| キー | 動作 |
|---|---|
| `Enter` | いまのノードの部分木の直後に、同じ深さで1件足す |
| `Tab` | いまのノードを部分木ごと1段深くする |
| `Shift+Tab` | いまのノードを部分木ごと1段浅くする |
| `Alt+↑` | いまのノードを、**同じ親を持つ兄弟の中**で1つ前の兄弟と入れ替える（深さは変えない） |
| `Alt+↓` | いまのノードを、**同じ親を持つ兄弟の中**で1つ後ろの兄弟と入れ替える（深さは変えない） |
| `Alt+C` | いまのノードの完了を切り替える（部分木ごと） |
| `↑` / `↓` | 見えている行の中で選択とフォーカスを1つ動かす |
| `Ctrl+Enter`（macOS では `⌘+Enter`） | いまのノードの詳細を開く |

- これらのキーの一覧を、**画面に常時見える凡例**として提示 SHALL する。
- キーに対応する UI 要素には、**ホバーヒント**（`attachTooltip` によるツールチップと `aria-keyshortcuts`）を併記 SHALL する。ただし `Tab`/`Shift+Tab`/`Alt+↑`/`Alt+↓`/`↑↓` のように**対応する単体の UI 要素を持たない**（行そのものに対するキーボード専用操作である）場合は、凡例での提示のみで足りる SHALL とする。
- **日本語入力の変換確定の `Enter` を、ノードの追加として扱ってはならない**（MUST NOT）。
- `Escape` は、編集中のタイトルを**確定前の値へ戻す** SHALL する。
- **タイトルが1文字も入っていないエフェメラルな追加入力**（`Enter` や末尾の＋で開く、兄弟を1件足すための入力欄）は、`Escape`（Esc）キーまたは `Delete` キーで閉じられる SHALL する。また、**タイトルが空のまま**その入力からフォーカスが離れた場合（他のノードをクリックした場合・ツリーの外へクリックした場合のどちらも含む）、**自動的に閉じる** SHALL する。ツリーの外へ離脱した場合は、上の「既定の展開は〜」要件の離脱時の挙動（フォーカスを奪い返さない）と同じルールに従う。
- 一方、**タイトルに1文字でも入っている**エフェメラルな追加入力は、フォーカスが離れても自動では閉じない（打ちかけの内容を失わないため）。`Enter` で確定するか `Escape` で明示的に取り消すまで残る。
- **エフェメラルな追加入力の中でも `Tab` / `Shift+Tab` が効く** SHALL する。`Tab` を押すと、追加先が「直前の兄弟の直後」から「**直前のタスクを親にした子**」へ切り替わり、入力欄は直前のタスクの下（1段深い位置）へ移る。`Shift+Tab` を押すと元の兄弟モードへ戻る。直前のタスクが無い場合（ツリー最初の1件目）は `Tab` は何もしない（エラーにしない）。この切り替えは既存ノードに対する `Tab`（部分木ごと1段深くする）と対称の操作感とする。
- **エフェメラルな追加入力で `Tab` / `Shift+Tab` を押しても、それまで打ち込んだ文字列は消えない** SHALL する（入力欄は再描画のたびに作り直されるが、打ちかけの文字列とカーソル位置を引き継ぐ）。
- **先頭のノードで `Alt+↑`、末尾のノードで `Alt+↓` を押しても何もしない** SHALL する（エラーにしない）。エフェメラルな追加入力にはこの操作は無い（入力欄自体は並べ替えの対象ではない）。
- `Alt+↑`/`Alt+↓` による並べ替えのあとも、対象ノードへの**選択とフォーカスは維持される** SHALL する。

#### Scenario: Enter で続けて打ち込める

- **WHEN** 空のツリーで1件目のタイトルを打って `Enter` を押し、続けて2件目のタイトルを打って `Enter` を押す
- **THEN** 同じ深さに2件が順に並び、途中でマウスを使う必要が無い

#### Scenario: Tab で直前の兄弟の下へ潜る

- **WHEN** 同じ深さで並ぶ2件のうち、後ろの1件で `Tab` を押す
- **THEN** それは前の1件の子になり、前の1件は容れ物になる

#### Scenario: Shift+Tab で親の兄弟に戻る

- **WHEN** 子として並んでいるノードで `Shift+Tab` を押す
- **THEN** それは親の**直後**に、親と同じ深さで並ぶ

#### Scenario: 一番浅いところでは Shift+Tab が効かない

- **WHEN** 根のノードで `Shift+Tab` を押す
- **THEN** ツリーは変わらず、エラーも出ない

#### Scenario: 変換確定の Enter でノードが増えない

- **WHEN** タイトルの入力中に日本語変換を確定する `Enter` を押す
- **THEN** 変換が確定するだけで、新しいノードは作られない

#### Scenario: 凡例が常に見えている

- **WHEN** タスク一覧を開く
- **THEN** `Enter` / `Tab` / `Shift+Tab` / `Alt+↑↓` / `Alt+C` / `↑↓` / `Ctrl+Enter` の意味が読める凡例が画面にある

#### Scenario: 空の追加入力は Escape や Delete で閉じる

- **WHEN** タイトルを1文字も入れずにエフェメラルな追加入力の中で `Escape` (Esc) または `Delete` を押す
- **THEN** 追加入力は閉じ、直前に触っていたノードへ選択とフォーカスが戻る

#### Scenario: 空の追加入力は他のノードをクリックしても閉じ、そのままそのノードを選べる

- **WHEN** タイトルを1文字も入れずにエフェメラルな追加入力を開いたまま、別のノードのタイトルをクリックする
- **THEN** 追加入力は閉じ、クリックしたノードが選択されてフォーカスが入り、そこから ↑↓ で移動できる

#### Scenario: 空の追加入力はツリーの外へクリックしても閉じる

- **WHEN** タイトルを1文字も入れずにエフェメラルな追加入力を開いたまま、ツリーの外（タスク一覧のカード群の外側）をクリックする
- **THEN** 追加入力は閉じ、フォーカスはツリーの中へ戻らない

#### Scenario: 文字が入っている追加入力は自動では閉じない

- **WHEN** エフェメラルな追加入力にタイトルを1文字以上打ってから、別のノードのタイトルをクリックする
- **THEN** 追加入力は閉じずに残り、打った内容も消えない

#### Scenario: 追加入力で Tab を押すと消えずに子モードへ切り替わる

- **WHEN** ノードの直後に開いたエフェメラルな追加入力（タイトルは空でも入力中でもよい）で `Tab` を押す
- **THEN** 追加入力は閉じずに残り、直前のタスクの子として作られる位置（1段深い位置）へ表示が移る。続けて `Enter` で確定すると、そのタスクの子として作られる

#### Scenario: 追加入力の子モードは Shift+Tab で兄弟モードに戻せる

- **WHEN** `Tab` で子モードへ切り替えたエフェメラルな追加入力で `Shift+Tab` を押す
- **THEN** 追加入力は元の兄弟モード（直前のタスクの直後・同じ深さ）へ戻る

#### Scenario: 追加入力の1件目では Tab が何もしない

- **WHEN** ツリーが空の状態で開いた1件目のエフェメラルな追加入力（直前のタスクが無い）で `Tab` を押す
- **THEN** 追加入力は閉じず、深さも変わらない。エラーも出ない

#### Scenario: Tab を押しても打ちかけの文字列は消えない

- **WHEN** エフェメラルな追加入力にタイトルを1文字以上打ってから `Tab` を押す
- **THEN** 追加入力は子モードへ切り替わった状態のまま残り、打ち込んだ文字列とカーソル位置は保たれる

#### Scenario: Alt+↓ で1つ後ろの兄弟と入れ替わる

- **WHEN** 同じ親を持つ兄弟 A・B・C（この順）のうち A を選び `Alt+↓` を押す
- **THEN** 並び順は B・A・C になり、深さ（親）は変わらない

#### Scenario: Alt+↑ で1つ前の兄弟と入れ替わる

- **WHEN** 同じ親を持つ兄弟 A・B・C（この順）のうち C を選び `Alt+↑` を押す
- **THEN** 並び順は A・C・B になり、深さ（親）は変わらない

#### Scenario: 先頭では Alt+↑ が効かない

- **WHEN** 兄弟の先頭のノードで `Alt+↑` を押す
- **THEN** 並び順は変わらず、エラーも出ない

#### Scenario: 末尾では Alt+↓ が効かない

- **WHEN** 兄弟の末尾のノードで `Alt+↓` を押す
- **THEN** 並び順は変わらず、エラーも出ない

#### Scenario: 子を持つノードを入れ替えても子はついてくる

- **WHEN** 子を2つ持つ容れ物 A と、その次の兄弟 B に対して A で `Alt+↓` を押す
- **THEN** A は B の後ろへ移り、A の子2つは A の下に付いたまま一緒に動く

#### Scenario: 入れ替えたあとも選択は移動したノードのまま

- **WHEN** ノード B を選んだ状態で `Alt+↓` を押して兄弟と入れ替える
- **THEN** 並べ替え後も B が選択・フォーカスされたままである
