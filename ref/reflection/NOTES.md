# 統合ワークスペース参照実装（reflection-timeline-workspace / issue #61）

`reflection-workspace.dc.html` が統合後の唯一の視覚参照。配色 hex・寸法トークンは
既存の `振り返り.dc.html`（#eef1f6 bg / #3b5bb5 accent / #e4e9f1 border / #f6f8fc panel /
#8b95a7 muted 等）をそのまま継承し、レイアウトのみ「左＝タイムライン(大)／右＝振り返り(小・常時)」
の2分割＋日付ストリップへ作り替えている。

## 既存 ref との差分

- `ref/reflection/振り返り.dc.html`（左本文＋右レール300pxの2カラム、右レールに
  「対象日」input + 「過去の振り返り一覧」）→ **廃止**。役割は統合参照の
  「右サイドバー（常時表示）」＋「上部の日付ストリップ」へ分割継承。
  - 右レールの「過去の振り返り一覧」→ 日付ストリップの気分ドット付きチップへ統合。
  - 本文エディタ・気分ピル・保存動線 → 右サイドバーへそのまま移設（見た目・挙動は不変）。
- `ref/timeline/TabTimeline.dc.html`（独立タイムラインタブの縦型日ビュー）→
  **タブとしては廃止**。描画そのもの（ラン結合・離席ドラッグ・ゴーストスロット・
  ポップオーバー等）は不変のまま、左メインの「タイムライン（完全版）」ビューとして
  そのままホストする（簡略化しない・複製を作らない）。
- 従来エディタ上部の「一日の配分」常設バー・右オーバーレイの簡略リボン（`buildRibbon`）
  → **廃止**。配分は左メインの独立ビューへ昇格、リボンは完全版タイムラインが役割を引き継ぐ。
- 「振り返りを終えて明日の計画へ →」（カンバンタブへ画面遷移）→ **廃止**。
  左メイン第3ビュー「明日の計画」（`tomorrow-plan-capture`）が振り返りタブ内で完結させる。

## この参照が示す骨格

- 上部: 気分ドット付き日付ストリップ（‹ › ＋チップ直接選択＋「今日」＋日付ピッカー）。
  対象日を持つビュー（タイムライン／一日の配分）＋右サイドバーの対象日を駆動する。
  **★変更（issue #67）**: 左メインが「明日の計画」ビューのときは非表示になる
  （盤面には表示対象日が無いため）。
- 左メイン（大）: `▤ タイムライン（完全版） / ◑ 一日の配分 / ✎ 明日の計画` を
  **ビュータブのみ**で切り替える。**★変更（issue #67）**: 横スクロール（scroll-snap）の
  デッキは廃止した。左メイン内の横スクロールは、埋め込みカンバン盤面（後述）の
  見切れた列をめくる操作専用になる。ビュー切替は対象日を変えない。
- 右サイドバー（小・常時表示）: **★変更（issue #67）**: タブ器になった。
  `本文`（気分ピル→本文エディタ→目標の日記。常時存在）に加え、左メインが
  「明日の計画」のときだけ `詳細` / `アクティビティログ` タブが現れる。
  カード選択で自動的に `詳細` タブへ、完了アーカイブで `アクティビティログ` タブへ切り替わる。
- **★新規（issue #67）**: 「明日の計画」ビューはチップ帯＋直接入力欄の下へ、
  登録用の**本物のカンバン盤面**（保留/未着手/進行中/完了）を埋め込む。列・カードの意匠は
  既存カンバン（`kb-*`）をそのまま流用し、振り返り専用の別意匠を描き直さない。
  盤面が左メイン幅に収まらない場合は完了列が見切れてよい（design D4）。

この html の2番目の `<main>` ブロックが「明日の計画」ビュー選択時の骨格を示す
（1番目はタイムラインビュー選択時＝旧来どおり変更なし）。
